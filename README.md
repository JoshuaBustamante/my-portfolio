# Personal Portfolio

A responsive portfolio built with plain HTML, CSS, and JavaScript. No installation or build step is required.

## Open

Open `index.html` in a browser. You can also use the VS Code Live Server extension to preview edits as you work.

Open `resume.pdf` for the current Information Technology resume. The Home page button opens the PDF directly. The editable source is `resume.html`, and its formal portrait is `resume-photo.png`.

## Personalize

- Update the name and Home and About copy with your own details.
- Edit the Skills items to match your experience.
- The Contacts section uses `joshuabustamante39@gmail.com`.
- The portfolio photo is stored as `joshua.jpg` in this folder. To use another photo, update the `.portrait` image `src` in `index.html` to its filename.
